Meta-каталог: усі дизайни в одному посиланні

Один каталог, один піксель, будь-яка кількість дизайнів будь-яких форматів. Дизайн для оголошення обирає шаблон Meta.

Раніше кожен дизайн означав окремий каталог: нове посилання, новий каталог у Commerce Manager, події пікселя розпорошуються. Meta-каталог збирає всі дизайни фіду в одне посилання.

Як це влаштовано

Кожен товар лишається одним рядком зі своїм справжнім ID. Усередині нього картинки всіх дизайнів під постійними номерами (Image number):

  • № 0 — головне фото товару, наприклад «Мінімал 4:5»
  • № 1 — «Мінімал 9:16»
  • № 2 — «Колаж 4:5»
  • № 3 — «Sale 4:5» … до № 19.

Формати можна змішувати як завгодно: п'ять різних 4:5, кілька 9:16, квадрати. Номер закріплений за дизайном і не змінюється, коли ви додаєте чи прибираєте інші.

Налаштування у Feedarte

  1. Фід → вкладка «Meta-каталог» → увімкнути. Усі опубліковані дизайни додадуться самі, а 4:5 і 1:1 стануть першими.
  2. За потреби додайте або приберіть дизайни. На № 0 поставте дизайн для стрічки.
  3. Для одного 9:16 позначте «Сторіз без шаблону».
  4. «Зберегти», скопіювати посилання, підключити в Commerce Manager як каталог (див. Підключення).

Налаштування в Meta

Без шаблону. Meta показує № 0. В оголошенні з форматом Single image і Advantage+ creative → Image touch-ups у сторіз піде дизайн, позначений «Сторіз без шаблону».

Будь-яка інша комбінація — через шаблон Meta:

  1. Commerce Manager → Image templates → Create.
  2. Шар Product на всю площу (X/Y = 0, розмір як у вкладки), вимкніть Crop to fit.
  3. На вкладках 1:1 і 4:5 вкажіть номер дизайну для стрічки, на вкладці 9:16 — номер дизайну для сторіз. Блок «Підібрати номери для шаблону Meta» у Feedarte показує ці номери, щойно ви оберете пару.
  1. В оголошенні: Image template → Choose template.
Порада

Тест нового дизайну = додати його в Meta-каталог + новий шаблон у Meta. Каталог, піксель і історія оптимізації лишаються ті самі.

Важливо

Попередній перегляд Ads Manager не завжди показує підстановку Image touch-ups. Шаблони перевіряйте в редакторі шаблону Meta, а живу рекламу — в Бібліотеці реклами.
