Підключення каталогу в Meta Commerce Manager

Data source за посиланням, розклад, налаштування обрізання, піксель і match rate.

Підключення

  1. Commerce Manager → Catalog → Data sources → Add items → Data feed.
  2. Вставте посилання з картки дизайну або з вкладки «Meta-каталог».
  1. Scheduled feed: оновлення щогодини.
  1. Валюту беремо з фіду, тож нічого не міняйте.

Налаштування каталогу

Catalog → Settings → Image cropping:

  • Fill frame with image — Meta обрізає під рамку.
  • Show entire image in frame — Meta вписує з рамками.

Креативи Feedarte вже мають потрібні пропорції, тому зазвичай краще «Fill frame».

Піксель і match rate

У Events → Catalog match rate Meta показує, яка частка подій пікселя (ViewContent, AddToCart, Purchase) зіставилась з товарами каталогу.

  • ID у каталогах Feedarte такі самі, як у магазині. Якщо збіг 0% в усіх каталогах, проблема в пікселі: події не надходять або в них немає content_ids. Перевірте Events Manager → Test events.
  • Не тримайте підключеними до пікселя десятки тестових каталогів. Відключайте ті, що не в рекламі.

Обрізання до квадрата

Каталожна карусель у стрічці за замовчуванням квадратна. Щоб показувати 4:5, використовуйте формат Single image або налаштування співвідношення в оголошенні. Див. Повноекранні сторіз і стрічка 4:5.

Спробуйте на своєму каталозі

Підключіть фід, оберіть шаблон і отримайте готовий фід з креативами для Meta і TikTok. Перші 14 днів — безкоштовно.
